# latitudesh_event (Data Source)

List account activity events (actions performed by users on your account), optionally filtered by author, project, target, action, or a creation-date range.

## Example Usage

```terraform
data "latitudesh_event" "recent" {
  filter_action = "server.power_on"
  page_size     = 10
}

output "event_total_count" {
  value = data.latitudesh_event.recent.total_count
}

output "event_actions" {
  value = [for e in data.latitudesh_event.recent.events : e.action]
}
```

Pagination is not followed automatically: `page_size` (API default 20) and
`page_number` (API default 1) control which single page of results is
returned. `total_count` reports the total number of events matching the
filters across all pages, which callers can use to decide whether to request
another page.

`id` identifies this query (a hash of the filters and page requested), not an
individual event.
