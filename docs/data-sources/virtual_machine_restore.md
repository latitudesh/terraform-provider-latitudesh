# latitudesh_virtual_machine_restore (Data Source)

Look up a virtual machine restore by `id`. Useful for polling a restore triggered outside Terraform (e.g. via the API or dashboard) until it reaches `Ready` and reading the ID of the resulting virtual machine.

## Example Usage

```terraform
data "latitudesh_virtual_machine_restore" "example" {
  id = "vmrst_..."
}

output "restored_virtual_machine_id" {
  value = data.latitudesh_virtual_machine_restore.example.virtual_machine_id
}

output "restore_status" {
  value = data.latitudesh_virtual_machine_restore.example.status
}
```

## Schema

### Required

- `id` (String) VM restore ID to look up.

### Read-Only

- `backup_id` (String) ID of the backup this restore was created from.
- `created_at` (String) Timestamp when the restore was created.
- `project` (String) Project (slug, falling back to ID) that owns the restore.
- `status` (String) Restore status: `Creating`, `Ready`, or `Failed`.
- `virtual_machine_id` (String) ID of the restored virtual machine. Null until the restore reaches `Ready`.
- `virtual_machine_name` (String) Name of the restored virtual machine. Null until the restore reaches `Ready`.
