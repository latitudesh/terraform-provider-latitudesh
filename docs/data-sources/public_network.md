# latitudesh_public_network (Data Source)

**Preview.** Available at locations where the `public_network` feature is enabled.

Retrieve a [public network](https://www.latitude.sh/dashboard) either by `id`, or by `project` and/or `site`. When looking up by `project`/`site`, the lookup fails if it matches more than one network — narrow it with `site` or switch to `id`.

## Example Usage

```terraform
resource "latitudesh_public_network" "network" {
  project = "proj_..."
  site    = "SAO2"
  size    = 28
}

output "network_ipv4" {
  value = latitudesh_public_network.network.ipv4
}

data "latitudesh_public_network" "by_id" {
  id = "pnet_..."
}

data "latitudesh_public_network" "by_project_and_site" {
  project = "proj_..."
  site    = "SAO2"
}
```

## Schema

### Optional

- `id` (String) Public network ID to look up. Mutually exclusive with `project`/`site` based lookup.
- `project` (String) The project (ID or slug) to filter by. Used together with `site` (or alone) when `id` is not set.
- `site` (String) The site slug to filter by. Used together with `project` (or alone) when `id` is not set.

### Read-Only

- `activated` (Boolean) True once a server has been added to the public network and the public network is ready to use.
- `capacity` (Number) Number of servers this public network can host.
- `created_at` (String) The timestamp for when the public network was created.
- `ips_free` (Number) Number of IPs still available on this public network.
- `ips_used` (Number) Number of IPs currently in use on this public network.
- `ipv4` (String) The IPv4 network in CIDR notation (e.g., "203.0.113.0/27")
- `ipv6` (String) The paired IPv6 /64 in CIDR notation (e.g., "2001:db8:1234::/64")
- `region_slug` (String) The slug of the location backing this public network.
- `size` (Number) IPv4 prefix length. Determines how many servers the public network can host.
