# latitudesh_marketplace_apps (Data Source)

List every published [marketplace app](https://www.latitude.sh/dashboard), optionally filtered by `category`. Only published apps are visible, and the `marketplace_apps` feature must be enabled for the team. To fetch a single app by `id`, `slug`, or `name`, use the [`latitudesh_marketplace_app`](marketplace_app) data source instead.

## Example Usage

```terraform
# List every published marketplace app.
data "latitudesh_marketplace_apps" "all" {}

output "marketplace_app_slugs" {
  value = [for app in data.latitudesh_marketplace_apps.all.apps : app.slug]
}

# Filter the catalog by category (case-insensitive).
data "latitudesh_marketplace_apps" "cms" {
  category = "cms"
}

output "cms_apps" {
  value = { for app in data.latitudesh_marketplace_apps.cms.apps : app.slug => app.name }
}
```
