# latitudesh_billing (Data Source)

Retrieve the billing usage of a project's current billing cycle: total amount, price, credit balance, and a per-product breakdown.

## Example Usage

```terraform
variable "project" {
  type    = string
  default = "proj_..."
}

data "latitudesh_billing" "usage" {
  project = var.project
}

output "billing_amount" {
  value = data.latitudesh_billing.usage.amount
}

output "billing_products" {
  value = data.latitudesh_billing.usage.products
}
```

`project` falls back to the provider-level `project` when unset; the data source errors with "Missing project" if neither is set.
