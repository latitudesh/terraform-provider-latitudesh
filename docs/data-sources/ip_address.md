# latitudesh_ip_address (Data Source)

Retrieve a management, additional, or elastic [IP address](https://docs.latitude.sh/reference/get-ips) by `id`, exact `address`, or the `server_id` it is assigned to. Exactly one of these must be set. `server_id` errors if the server has more than one IP assigned (e.g. a management IP plus an additional IP) — use `address` to disambiguate in that case.

## Example Usage

```terraform
data "latitudesh_ip_address" "by_id" {
  id = "ip_XXXXXXXX"
}

data "latitudesh_ip_address" "by_address" {
  address = "203.0.113.10"
}

data "latitudesh_ip_address" "management" {
  server_id = "sv_XXXXXXXX"
}

output "management_ip_address" {
  value = data.latitudesh_ip_address.management.address
}
```
