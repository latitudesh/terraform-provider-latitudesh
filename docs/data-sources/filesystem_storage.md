# latitudesh_filesystem_storage (Data Source)

Retrieve a [filesystem storage](https://www.latitude.sh/dashboard) volume by `id`, or by `name` (optionally narrowed with `project`).

## Example Usage

```terraform
resource "latitudesh_project" "filesystem_storage" {
  name              = "Filesystem storage example"
  environment       = "Development"
  provisioning_type = "on_demand"
}

resource "latitudesh_filesystem_storage" "example" {
  project    = latitudesh_project.filesystem_storage.id
  name       = "shared-data"
  region     = "ASH"
  size_in_gb = 1500
  protocols  = ["nfs4"]
}

data "latitudesh_filesystem_storage" "by_id" {
  id = latitudesh_filesystem_storage.example.id
}

data "latitudesh_filesystem_storage" "by_name" {
  name    = "shared-data"
  project = latitudesh_project.filesystem_storage.id
}
```

## Schema

### Optional

- `id` (String) Filesystem identifier to look up.
- `name` (String) Filesystem name to look up. Names are not guaranteed unique; the first match wins, so narrow the search with `project` if the lookup is ambiguous.
- `project` (String) Project (ID or slug) to narrow a `name` lookup to. Ignored when `id` is set: an `id` lookup always reports the owning project the API returns, whatever was configured here.

### Read-Only

- `file_endpoint` (String) Hostname of the NFS endpoint backing the filesystem. Null for filesystems not backed by high performance file storage.
- `nfs_mount_path` (String) Path of the NFS view backing the filesystem. Null for filesystems not backed by high performance file storage.
- `protocols` (Set of String) NFS protocol version(s) the filesystem was requested to be mounted with.
- `region` (String) Site slug where the filesystem is provisioned.
- `size_in_gb` (Number) Filesystem size, in GB.
- `storage_class` (String) Backend storage tier the API assigned based on `region` (`standard` or `high_performance`).
