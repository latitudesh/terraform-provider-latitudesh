# latitudesh_api_key (Data Source)

Retrieve an [API key](https://www.latitude.sh/dashboard/api-keys) by `id` or `name`.

## Example usage

```terraform
resource "latitudesh_api_key" "ci" {
  name        = "ci-deploy-key"
  read_only   = false
  allowed_ips = ["203.0.113.10", "198.51.100.0/24"]
}

data "latitudesh_api_key" "by_id" {
  id = latitudesh_api_key.ci.id
}

output "ci_api_key_token" {
  value     = latitudesh_api_key.ci.token
  sensitive = true
}

output "ci_api_key_last_slice" {
  value = data.latitudesh_api_key.by_id.token_last_slice
}
```

> **Note:** The full token is only ever returned by the create call, so it is not exposed by this data source. See the `latitudesh_api_key` resource.

### Optional

- `id` (String) API key identifier to look up.

### Read-Only

- `allowed_ips` (List of String) List of allowed IP addresses or CIDR ranges for this API key.
- `api_version` (String) The API version associated with this API key.
- `created_at` (String) Timestamp when the API key was created.
- `last_used_at` (String) The last time a request was made to the API using this key.
- `read_only` (Boolean) Whether the API key is read-only.
- `token_last_slice` (String) The last 5 characters of the token.
- `updated_at` (String) Timestamp when the API key was last updated.
- `user_email` (String) The email of the user that owns this API key.
- `user_id` (String) The identifier of the user that owns this API key.
