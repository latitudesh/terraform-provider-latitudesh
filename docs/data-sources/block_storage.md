# latitudesh_block_storage (Data Source)

Retrieve a [block storage](https://www.latitude.sh/dashboard) volume by `id`, or by `name` (optionally narrowed with `project`).

## Example Usage

```terraform
resource "latitudesh_project" "block_storage" {
  name              = "Block storage example"
  environment       = "Development"
  provisioning_type = "on_demand"
}

resource "latitudesh_block_storage" "example" {
  project    = latitudesh_project.block_storage.id
  name       = "app-data"
  region     = "ASH"
  size_in_gb = 100
}

data "latitudesh_block_storage" "by_id" {
  id = latitudesh_block_storage.example.id
}

data "latitudesh_block_storage" "by_name" {
  name    = "app-data"
  project = latitudesh_project.block_storage.id
}
```

## Schema

### Optional

- `id` (String) Volume identifier to look up.
- `name` (String) Volume name to look up.
- `project` (String) Project (ID or slug) to narrow a `name` lookup to (ignored when `id` is set). Also returned as the volume's owning project when looking up by `id`.

### Read-Only

- `connector_id` (String) Connector identifier used to reach the volume over NVMe-TCP.
- `namespace_id` (String) NVMe namespace identifier assigned to the volume.
- `region` (String) Site slug where the volume is provisioned.
- `size_in_gb` (Number) Volume size, in GB.
