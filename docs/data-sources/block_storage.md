# latitudesh_block_storage (Data Source)

Retrieve a [block storage](https://www.latitude.sh/) volume by `id`, or by `name` scoped to a `project`.

## Example Usage

```terraform
variable "project" {
  type    = string
  default = "proj_..."
}

resource "latitudesh_block_storage" "example" {
  project    = var.project
  name       = "example-volume"
  region     = "SAO" # site/region slug; not returned by the read API, see docs
  size_in_gb = 100
}

data "latitudesh_block_storage" "by_id" {
  id = latitudesh_block_storage.example.id
}

data "latitudesh_block_storage" "by_name" {
  project = var.project
  name    = latitudesh_block_storage.example.name
}

output "block_storage_id" {
  value = latitudesh_block_storage.example.id
}

output "block_storage_namespace_id" {
  value = latitudesh_block_storage.example.namespace_id
}
```

`project` falls back to the provider-level `project` when unset, and is only used (and only returned) for a `name` lookup — it is ignored, and left null, when looking up by `id`.

> **Note:** `region` is never populated from the API (the read endpoint has no such field); it is always null on this data source.

## Schema

### Optional

- `id` (String) Volume identifier to look up. Mutually exclusive with `name`.
- `name` (String) Volume name to look up within `project`. Mutually exclusive with `id`.
- `project` (String) Project (ID or slug) to search when looking up by `name`. Falls back to the provider-level `project` when unset. Not used, and not returned, when looking up by `id`.

### Read-Only

- `cluster_user` (String) Ceph cluster user used to connect to the volume. Returned only for dashboard-origin requests; null until the volume is provisioned.
- `connector_id` (String) Connector ID of the volume
- `created_at` (String) The timestamp for when the volume was created
- `initiators` (Attributes List) NVMe initiators (clients) currently allowed to mount the volume. (see [below for nested schema](#nestedatt--initiators))
- `keyring` (String, Sensitive) Cephx keyring secret used to connect to the volume. Returned only for dashboard-origin requests; null until the volume is provisioned.
- `namespace_id` (String) Namespace ID of the volume
- `region` (String) The region (site) slug the volume was created in. Not returned by the volume read API, so this is always null.
- `size_in_gb` (Number) Size of the volume in GB
- `volume_path` (String) Path of the volume inside the cluster. Returned only for dashboard-origin requests; null until the volume is provisioned.
