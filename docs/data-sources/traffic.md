# latitudesh_traffic (Data Source)

Read-only traffic reporting: consumption over a date window (`Traffic.Get`) and quota (`Traffic.GetQuota`), both scoped by an optional `project`.

## Example Usage

```terraform
variable "project" {
  type    = string
  default = "proj_..."
}

data "latitudesh_traffic" "usage" {
  project  = var.project
  date_gte = "2024-04-01T00:00:00Z"
  date_lte = "2024-04-30T23:59:59Z"
}

output "traffic_total_outbound_gb" {
  value = data.latitudesh_traffic.usage.total_outbound_gb
}

output "traffic_quota_per_project" {
  value = data.latitudesh_traffic.usage.quota_per_project
}
```

`project` falls back to the provider-level `project` when unset; if neither is set, the report covers every project the token can access.

Quota is reported per region under `quota_per_project.*.quota_per_region`. Each region carries exactly one of `quota_in_tb` or `quota_in_mbps` — which one is populated depends on a project-level feature flag, so read both and expect the other to be null.

## Schema

### Required

- `date_gte` (String) Start of the consumption window, in ISO8601 format (e.g. `2024-04-01T00:00:00Z`).
- `date_lte` (String) End of the consumption window, in ISO8601 format (e.g. `2024-04-30T23:59:59Z`). The window between `date_gte` and `date_lte` must not exceed 366 days.

### Optional

- `project` (String) Project (ID or slug) to restrict traffic and quota to. Falls back to the provider-level `project` when unset; if neither is set, the report covers every project the token can access.
- `server` (String) Server ID to restrict traffic consumption to. Not applied to the quota lookup.

### Read-Only

- `from_date` (Number) Start of the reported window, as a unix timestamp.
- `id` (String) Traffic consumption report identifier.
- `quota_id` (String) Traffic quota report identifier.
- `quota_per_project` (Attributes List) Per-project traffic quota breakdown. (see [below for nested schema](#nestedatt--quota_per_project))
- `quota_type` (String) Quota resource type, as returned by the API.
- `regions` (Attributes List) Per-region traffic consumption breakdown. (see [below for nested schema](#nestedatt--regions))
- `to_date` (Number) End of the reported window, as a unix timestamp.
- `total_inbound_95th_percentile_mbps` (Number) The 95th percentile of inbound bandwidth across all regions. This is a global percentile, not a sum of regional percentiles. Value in Mbps.
- `total_inbound_gb` (Number) Total inbound traffic across all regions, in GB.
- `total_outbound_95th_percentile_mbps` (Number) The 95th percentile of outbound bandwidth across all regions. This is a global percentile, not a sum of regional percentiles. Value in Mbps.
