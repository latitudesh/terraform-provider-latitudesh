# latitudesh_virtual_machine_backup (Resource)

Triggers a backup of a [Latitude.sh](https://latitude.sh/) virtual machine. The resource waits for the backup to reach a terminal status (`Ready` or `Failed`) before completing.

There is no update endpoint, so changing `virtual_machine` forces a new resource — which triggers a brand new backup rather than modifying one in place.

## Example Usage

```terraform
resource "latitudesh_virtual_machine" "bastion" {
  name             = "bastion"
  plan             = "vm-small"
  operating_system = "ubuntu_24_04_x64_lts"
}

resource "latitudesh_virtual_machine_backup" "bastion" {
  virtual_machine = latitudesh_virtual_machine.bastion.id
}

data "latitudesh_virtual_machine_backup" "bastion" {
  id = latitudesh_virtual_machine_backup.bastion.id
}
```
